# 🏦 Global Payment Center — Fixed Version

A **secure, idempotency-safe** backend for payment processing built with **Node.js**, **Express**, and **PostgreSQL**.  
This version fixes the concurrency and duplicate-transaction issues found in the original *Global Payment Center* repository.

---

## 🚀 Features

✅ **Idempotency Handling** — prevents duplicate charges caused by retries or concurrency  
✅ **Node.js + Express** — lightweight, scalable backend  
✅ **PostgreSQL Integration** — uses `pg` for database operations  
✅ **Webhook Support** — receive and record provider events  
✅ **Simple Frontend** — included demo HTML form  
✅ **Concurrency Test Tool** — simulate 8 simultaneous payment requests  
✅ **Production-Ready** — clean structure, environment isolation, `.gitignore` included
